开发者指南 / OpenAI 兼容 API

用 OpenAI 兼容接口发起第一条请求

如果你的工具支持自定义 OpenAI 兼容 API 地址，可以先用下面的请求验证密钥和模型。不同工具对接口格式的支持可能不同，请先确认工具的实际配置要求。

1. 创建并保管密钥

注册或登录 WaveNode，进入密钥管理创建 API Key。不要把密钥放在公开仓库、截图或前端浏览器代码中。

2. 查看可用模型

用密钥查询当前账号可访问的模型列表；选择返回列表中的模型 ID，而不是照搬文章中的固定型号。

curl https://api.wavenode.org/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

3. 发起聊天补全请求

把 YOUR_MODEL_ID 换成上一步返回的模型 ID。HTTP 状态码和响应正文会帮助定位权限、模型或余额问题。

curl https://api.wavenode.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"你好"}]}'

在支持自定义 OpenAI 兼容 Base URL 的客户端中，基础地址填写 https://api.wavenode.org/v1；若客户端要求完整接口地址，则按其文档填写具体路径。不要在不支持第三方地址的工具中强行替换。

下一步

如果遇到 HTTP 429，阅读限流与额度排查指南；模型的可用状态以模型广场及实际接口响应为准。
